# External validation of an echocardiographic EF prediction model

Code used for the University of Sheffield / Insigneo project:

**External validation of a machine learning model that estimates ejection fraction from 4 chamber echocardiogram images**

This repository contains code for:
- validation-data preprocessing and AVI conversion
- model inference
- EF performance evaluation
- temporal diagnostic testing
- generation of poster figures

## Data

The datasets are not distributed with this repository. Users should obtain the
original and validation data from their respective official sources.
